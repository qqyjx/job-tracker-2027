# 2027 秋招投递清单

把散落在各家官网、招聘系统和公众号里的校招岗位收敛成一张表，标好机构、岗位、
城市、截止日期，以及每个岗位为什么值得投。

## 打开

**在线** → https://qqyjx.github.io/job-tracker-2027/

这个链接打不开就是仓库的 GitHub Pages 还没启用。两个办法：

- 启用 Pages：仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，
  下面 Branch 一行由 `None` 改成 **`main`** ＋ **`/ (root)`**，点 **Save**。
  Branch 默认是 None，不改这一行 Pages 不会生效。
- 或者直接下载 `index.html`，用浏览器打开，功能完全一样。

## 用法

页面分七组，越靠上越紧急：

| 分组 | 说明 |
|---|---|
| 上海选调 | 已开放报名。235 个岗位里筛出专业与政治面貌都符合的 7 个 |
| 进行中 | 正在填表或已进入流程 |
| 开放投递 | 网申已开，按截止日先后处理 |
| 互联网与文娱 | 多数招满即止，别等到截止日 |
| 央国企职能岗 | 党群、行政、宣传、人力这类，专业目录常写"不限" |
| 即将开放 | 盯公告发布，报名窗口通常只有几天且不补报 |
| 考试路径 | 选调、国考、省考、事业单位，需要提前备考 |
| 明年春季 | 文艺院团按事业单位节奏走，主战场在 3—5 月 |

每行右侧的状态可以点，在 **待投 → 已投 → 不投** 之间循环。状态存在自己浏览器里，
换设备或清缓存会重置。

顶部是汇总：已投、待投、待开放、14 天内截止的数量，加上最近一个截止日的倒计时。
每行左侧的竖条是优先级，深色为高。

## 关于数据

- 日期和链接来自实际打开过的官网页面，但招聘系统随时可能调整，**以官网公告为准**。
- 截止日为空表示公告未标注或岗位尚未发布，需要持续关注。
- 「即将开放」「明年春季」两组的时间是按往年规律推算的，不是官方公告。
- 有些系统不提供网页投递入口，或详情页读不到完整要求（上海电气的详情页是
  canvas 渲染、深圳广电只能走公众号），表里都已注明要本人登录或关注公众号确认。
